
# ResumeCraft – Development Prompts

## Prompt 1 – Initial Application

Build a professional Resume Builder using HTML, CSS and vanilla JavaScript with a live A4 resume preview and PDF export.

## Prompt 2 – Resume Templates

Add three visually different resume templates:
1. Professional Blue
2. Minimal Black
3. Modern Purple

Allow users to switch templates without losing entered information.

## Prompt 3 – Save and Load

Implement LocalStorage functionality, automatic restoration, JSON export and JSON import.

## Prompt 4 – PDF Improvements

Improve A4 print formatting, multi-page resume support and selectable PDF text.

## Prompt 5 – Drag and Drop

Implement drag-and-drop functionality to rearrange resume sections and preserve their order when saving and loading data.

## Development Notes

- Project built using VS Code.
- HTML, CSS and JavaScript used.
- No external API or database required.
- Tested using a local browser environment.
