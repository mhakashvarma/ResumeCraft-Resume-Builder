
# ResumeCraft – Smart Resume Builder

## Project Overview

ResumeCraft is an offline, browser-based Resume Builder application developed using HTML, CSS and JavaScript.

It allows users to create professional resumes, preview changes instantly, choose from multiple templates and export their resumes as PDF files.

All personal information stays on the user's device.

## Features

- User-friendly resume creation dashboard.
- Live A4 resume preview.
- Three professional resume templates.
- Personal information management.
- Education, skills and project sections.
- Experience section.
- Drag-and-drop section reordering.
- Export resume as PDF.
- Save resume information using LocalStorage.
- Automatic restoration of saved information.
- Export resume data as JSON.
- Import previously saved JSON files.
- Multi-page resume support.
- Responsive interface.
- Offline functionality.

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open index.html.
4. Right-click and select Open with Live Server.
5. Start creating your resume.

No API keys, database or paid services are required.

## How to Use

1. Enter your personal information.
2. Add education, skills, projects and experience.
3. Select one of the three resume templates.
4. Rearrange sections using drag and drop.
5. Preview your resume instantly.
6. Save your information.
7. Export the resume as PDF.
8. Export or import JSON data when needed.

## Privacy

ResumeCraft stores resume information locally in the browser using LocalStorage.

No external server or database is used.
